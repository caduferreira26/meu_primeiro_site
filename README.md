Meu Primeiro Projeto — Desenvolvimento Web

05 de outubro de 2026 

Este é o meu primeiro site construído do zero, escrito à mão, com cada linha de código sendo um passo novo no mundo da programação. Não é perfeito, mas é meu — e é o começo de tudo.

O que aprendi e pratiquei aqui:
- Estruturação de páginas com HTML5
- Criação de múltiplas páginas e navegação entre elas
- Conexão com arquivo de estilo externo
- Organização de projeto em pastas
- Uso de fontes do Google Fonts
- Caminhos e links entre arquivos

Sobre o projeto
Está em construção. Vai crescer, vai mudar, vai ficar mais bonito e mais funcional. Mas esta versão marca o momento em que parei de apenas querer aprender e comecei a fazer.
